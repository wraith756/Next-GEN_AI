Database Schema — SQLite

Existing tables kept as-is. Two new tables added for chat sessions.

EXISTING TABLES (unchanged)
sys_command
id INTEGER PRIMARY KEY
name TEXT
path TEXT
web_command
id INTEGER PRIMARY KEY
name TEXT
url TEXT
contacts
id INTEGER PRIMARY KEY
name TEXT
mobile_no TEXT
email TEXT
address TEXT
info
name TEXT
designation TEXT
mobileno TEXT
email TEXT
city TEXT
NEW TABLES (chat sessions)
chat_sessions
id INTEGER PRIMARY KEY
title TEXT -- "Chat #1", user-renamed
created_at DATETIME
updated_at DATETIME
One row per tab in the tab bar
chat_messages
id INTEGER PRIMARY KEY
session_id INTEGER → chat_sessions.id
role TEXT -- "user" | "assistant"
content TEXT
created_at DATETIME
Every message in every session
session_summaries
id INTEGER PRIMARY KEY
session_id INTEGER → chat_sessions.id
summary TEXT -- compressed context
message_count INTEGER
created_at DATETIME
After 10 messages → Groq 8b compresses history into this summary. Next AI call prepends the summary instead of all 10 messages.
